# Deployment

This folder contains Docker and deployment configurations.

| File | Purpose |
|------|---------|
| `docker-compose.yml` | Local dev stack (Kafka, Spark, PostgreSQL, Elasticsearch) |
| `Dockerfile.backend` | Backend container image |
| `Dockerfile.frontend` | Frontend container image |
| `.env.example` | Environment variable template |
